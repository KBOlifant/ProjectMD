    Words used on this page

    Component
    A piece of the screen written in React (a .tsx file), for example the URL bar.
    Provider / context
    Shared memory that many screens can read, for example who is signed in.
    Service
    A C# class that does one job. ASP.NET hands it to whoever needs it ("dependency injection").
    Middleware
    A checkpoint on the server. Every request walks through all of them, in order.
    Controller / endpoint
    The C# method that answers one web address, like POST /api/scans.
    Token (JWT)
    A signed pass from Firebase that proves who you are. It expires after 1 hour and is renewed automatically.
    Playwright
    A library that lets code drive a real web browser: open pages, click, scroll, take screenshots.
    Chromium (headless)
    The open-source browser behind Chrome. "Headless" means it runs with no window.
    Browser context
    A brand-new private window with its own cookies. Made for one scan, then thrown away.
    Route / intercept
    Catching each request the page wants to make before it leaves the browser.
    evaluate
    Running a small piece of JavaScript inside the loaded page and reading back the answer.
    SSRF
    A trick where a website makes our server fetch private addresses. The proxy blocks this.
    Prompt
    The text sent to the AI. The system prompt holds the fixed rules; the user message holds the facts about this page.
    Transaction
    A group of database steps that either all happen or none do.
